# Cell_Aegis
Cell Aegis an upgraded and renamed version of "Battery Guardian 3.o" which helps to remind and save the battery when it reaches 20 and 80 percentage.

# Version Histories
Battery Guardian 1st & 2nd Version :- It was very simple, main purpose of this program was to shutdown my pc when i am listing songs and sleep cuz it was my habbit and that's why i created it. It only has the feature of beeping before shutdown and was completely running on terminal, no any .exe for this (cuz i was learning!).

Battery Guardian 3.o (The upgraded version) :- Now it's upgraded with some cool features and auto startup with startup folder. I added the email feature (the biggest update) with updated logics, and voice feature too with some more advanced alearts and packed into .exe file as said.

Cell Aegis :- REnamed after battery guardian 3.o.
